# 数据空间管理 UI/UX 重设计方案（v2）

## 设计目标

1. 左侧数据空间卡片铺满屏幕余下高度，新建/删除空间放在顶部扁平化
2. 资源管理（目录/数据集操作）合并到数据空间卡片内
3. 右侧上传与导入采用页签切换三种方式
4. 整体扁平化，减少卡片嵌套

## R Shiny 布局约束分析

R Shiny (shinydashboard) 的 UI 能力：
- `fluidRow` + `column` 做 12 列栅格
- `box()` 做卡片容器
- `tabBox()` 做页签容器
- CSS 可覆盖默认样式
- 无法原生做 flex-grow / 填满剩余高度（需 CSS hack）

**可行方案：** 用 CSS `calc(100vh - offset)` 让左右面板铺满屏幕，内部用 `overflow-y: auto` 处理溢出。

## 实现要点

### 1. 左侧数据空间卡片

```
┌──────────────────────────────┐
│ ▸ 数据空间                    │  ← 卡片标题
├──────────────────────────────┤
│ [空间名 ▼]  [+] [🗑]         │  ← 顶栏：选择器 + 新建/删除按钮（扁平 inline）
│ [新空间名称____] [新建空间]    │  ← 新建表单（可折叠）
├──────────────────────────────┤
│ ▼ 空间A                      │
│   📁 根目录                   │  ← 可交互导航树
│     📊 adsl (300x15)         │
│     📊 adae (1200x20)        │
│   📂 安全性数据               │
│     📊 lb (5000x8)           │
│ ▶ 空间B                      │
├──────────────────────────────┤
│ 新建目录: [________] [创建]   │  ← 底部资源管理栏（扁平 inline）
│ [删除目录] [删除数据集]        │
└──────────────────────────────┘
│ ← CSS: height: calc(100vh - 180px); overflow-y: auto
```

### 2. 右侧上传与导入卡片

```
┌──────────────────────────────────────────────┐
│ ▸ 上传与导入                                  │  ← 卡片标题
├──────────────────────────────────────────────┤
│ ┌──────────┬──────────┬──────────┐           │
│ │ 单文件上传 │ 批量导入  │ 服务器导入 │  ← tabBox  │
│ ├──────────┴──────────┴──────────┤           │
│ │                                  │           │
│ │  单文件上传页签：                  │           │
│ │  [选择文件] [CSV编码 ▼]           │           │
│ │  [上传并保存到当前目录]            │           │
│ │                                  │           │
│ └──────────────────────────────────┘           │
│ ← CSS: height: calc(100vh - 180px); overflow-y: auto
```

### 3. 顶部统计卡（可选）

将 `db_overview_cards` 放在两个卡片上方，作为一行紧凑统计条。

## CSS 关键

```css
  height: calc(100vh - 200px);  /* 减去 header + 顶卡 + padding */
  display: flex;
  flex-direction: column;
}

  flex: 1;
  display: flex;
  flex-direction: column;
}
.db-main-panel .box-body {
  flex: 1;
  overflow-y: auto;
}
```
