# 文档中的公共壳与样板推进口径清理设计

## 背景

- 前端运行页与核心文档中的明显开发口径已完成多轮清理。
- `README.md`、`PROJECT_GUIDE.md` 与 `DEPLOYMENT_GUIDE.md` 仍保留一批“公共壳接入/样板推进”类表述，例如：
  - `现已接入`
  - `现已继续接入`
  - `第三阶段样板已落到`
  - `样板已继续落到`
  - `结果区当前已继续统一`
  - `第一批 UI 归一当前已接入`
- 这类表述描述的是推进过程，而不是稳定事实。

## 目标

- 将文档中的推进口径改为稳定的模块状态说明。
- 保留模块边界、适用范围与不变的业务链路说明。
- 新增轻量守卫测试，阻断这些短语回流。
- 同步更新相关文档契约预期。

## 非目标

- 不重写统计分析、统计图形或公共壳章节结构。
- 不修改业务代码或 UI 守卫测试逻辑。

## 范围

### 本轮处理文件

- `README.md`
- `PROJECT_GUIDE.md`
- `DEPLOYMENT_GUIDE.md`
- `tests/root/test_access_boundary_guard.R`

### 本轮处理位置

- 公共 UI 壳接入说明
- 统计分析子模块样板覆盖说明
- 统计分析结果区与公共扩散源说明

## 改写原则

- 将“现已接入/现已继续接入”改为“使用/采用”。
- 将“样板已落到/已继续落到”改为“样板覆盖/样板适用于”。
- 将“当前已继续统一”改为“已统一”。
- 将“第一批 UI 归一当前已接入”改为“第一批 UI 归一已接入”。

## 守卫测试
